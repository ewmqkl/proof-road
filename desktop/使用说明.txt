证明之路 · 从命题逻辑到代数定理   ——   Windows 桌面版 v0.2
================================================================

一、怎么用
----------------------------------------------------------------
双击 ProofRoad.exe 就能玩。不用安装，不用联网，不用装任何运行时。

第一次打开如果 Windows 弹出蓝色的“Windows 已保护你的电脑”：
    点「更多信息」→「仍要运行」。
这是 SmartScreen 对“没有代码签名的新程序”的默认提醒，不是报毒。
不想看到它，也可以先右键 exe →「属性」→ 勾选底部的「解除锁定」→ 确定。

二、有两个版本，用哪个
----------------------------------------------------------------
ProofRoad.exe       推荐。32 位程序，32 位 / 64 位 / ARM64 的
                    Windows 10、Windows 11 都能直接跑，兼容面最广。
ProofRoad-x64.exe   64 位程序。只有极少数机器才需要它，典型是 ARM64
                    设备上系统没装 32 位的 WebView2 运行时。平时不用管。

两个文件功能完全一样，用哪个都行，文件名也可以随便改。

直接发给别人的那个 zip 里只放了 ProofRoad.exe 这一个（它在三种架构上都能跑）；
如果你确实需要 64 位版，在发布目录 release\ 里另取 ProofRoad-x64.exe 即可。

三、运行环境与兼容性
----------------------------------------------------------------
* 系统：Windows 10（1607 及以上）/ Windows 11，32 位与 64 位均可
* .NET 运行时：不需要，运行时已经打进 exe 里了
* 显示引擎：优先用系统自带的 Microsoft Edge WebView2；万一这台机器没有，
            会自动改用 Edge / Chrome 的应用窗口模式，观感几乎一样，进度照常保存
* 不需要管理员权限，不弹 UAC，不弹防火墙提示
* 可以放在 U 盘、只读目录、网络共享上运行——程序只往
  %LOCALAPPDATA%\ProofRoad 写自己的存档和日志

一个说明：为了让游戏进度能存下来，程序会在本机回环地址 127.0.0.1 上
开一个小端口（47100-47103）给内置的网页引擎用。这个端口只对本机可见，
外网连不上，程序退出即消失。

四、快捷键
----------------------------------------------------------------
F11 或 Alt+Enter    全屏 / 退出全屏（Esc 也可退出全屏）
F5 或 Ctrl+R        重新载入
Ctrl+加号 / 减号     缩放（Ctrl+0 复原）
F12                 开发者工具（一般用不到）
F1                  版本信息

五、存档在哪里
----------------------------------------------------------------
%LOCALAPPDATA%\ProofRoad\
    WebView2\          游戏进度（哪些关已通过）、41 项成就、统计、史话阅读记录，
                       以及每一关“推到一半”的证明现场
    window.json        上次的窗口大小与位置
    proof-road.log     运行日志，出问题时把它发出来就行
把整个 ProofRoad 文件夹删掉 = 彻底重置进度，程序本体不受影响。

游戏内部还有一套更细的存档（档案室 → 存档）：
  * 每一步都会自动记下现场，关掉窗口再打开就接着上次推；
  * 有 3 个手动存档槽位，可以命名、可以随时读回；
  * 可以把存档导出成 .json 文件，或取出一段“存档文本”复制走，
    在另一台机器上导入即可继续（成就、统计、史话阅读都会一起过去）。
  * 游戏里的「重置进度」会清空进度、统计、成就、史话与自动存档，
    但**不会删除手动存档槽**——那是你的备份，要删请单独点“删除”。

六、出问题了怎么办
----------------------------------------------------------------
1) 窗口一片空白、半天没反应
   看 %LOCALAPPDATA%\ProofRoad\proof-road.log 的最后几行。

2) 提示“需要 Microsoft Edge WebView2 运行时”
   说明这台机器既没有 WebView2 运行时，也没有 Edge / Chrome。
   点窗口里的按钮装一次即可（免费，约 2 MB，装完就能用）：
   https://go.microsoft.com/fwlink/p/?LinkId=2124703

3) 被杀毒软件当成可疑程序
   加白名单即可。程序不联网、不写系统目录、不需要管理员权限；
   它会把少量自己的运行库解到 %TEMP%\.net\ProofRoad（约 0.3 MB），
   这是 .NET 单文件程序的正常行为。

4) 觉得窗口太小 / 太大 / 跑到屏幕外面了
   窗口大小与位置会被记住。想恢复默认，删掉
   %LOCALAPPDATA%\ProofRoad\window.json 再打开即可。

七、这个 exe 是怎么来的
----------------------------------------------------------------
它不是另一个程序，只是给仓库里的网页套了一个原生窗口：

    proof-road-standalone.html      ← 整个游戏（约 408 KB，零外部依赖）
    desktop/*.cs                    ← .NET 9 + WebView2 外壳，约 1000 行
    tools/build-single.mjs          ← 把 src/ 下的模块打成上面那个 HTML
    tools/make-icon.mjs             ← 生成图标（纯 Node 手写 PNG / ICO 编码）
    tools/build-desktop.mjs         ← 把 HTML 内嵌进 exe，发布成自包含单文件

想自己重新编译，在工作区根目录执行：

    node tools/build-desktop.mjs --zip

（需要 .NET 9 SDK；不需要装 Visual Studio。）

游戏源码、155 项自动化测试、全部构建脚本都在工作区里，可以自行核对。

八、关于新手引导与数学史
----------------------------------------------------------------
第一次进入证明台时会自动弹出一段分步引导，把每一块面板讲一遍，接着逐关
讲解 L0 的十六关。引导随时可以点「跳过引导」退出；跳过过的关卡不会自动
再弹，想重看点证明台右下角的「本关引导」；想整体关掉，在「档案室」右侧
把开关切一下即可（重置进度后恢复默认）。

每一关还有一条「数学史 · 这一关的来历」：这条规则或这个公式是谁、在什么
时候、为什么被提出来的。全部 34 条史话收在「档案室 → 数学史」里，按时代
分组，可以展开读全文，也可以从那里直接跳到相关关卡。
