设计说明

这一节是文档，不属于界面本身

① 这次找到了真正的设计标准

官方仍然没有公开设计规范，但社区里有一个成体系的、可安装的设计 skill：

  • YunYouJun/ak-ui（MIT）—— 受方舟界面启发的独立设计语言 + 可用的 CSS 基础库，并带一个正式发布的 AI Skill：npx skills add YunYouJun/ak-ui --skill ak-ui。
  • skill 里含 design-language.md（设计契约）、tokens.md（Token 契约）、official-site.md（官网取证）、motion.md、quality-checklist.md（验收清单）。
  • 第一版样片之所以不像，是因为我没读这些：面板该是纸面白（--ak-surface-panel 是 rgba(253,253,251,.9)，我却全做成了深灰），标题该是 3rem 粗衬线（我用了 22px），几何该是内嵌描边框 + 底部信号条 + 斜向断口（我全漏了）。

本页直接 vendor 了 @yunyoujun/ak-ui@1.1.0 的编译产物（vendor/ak-ui.min.css，MIT，原样未改），项目自有组件全部通过 --ak-* 语义 token 取值。官方素材边界：ak-ui 明确不还原任何具体游戏画面，本页也没有任何游戏 Logo／立绘／纹理／截图。

② ak-ui 设计契约（本次实际遵守的）

  • 先层级后装饰：每块先有大字号主命令、支撑上下文、低语元信息，再谈线条。
  • 有目的的非对称几何：切角、内嵌描边、错位线条，但不给每个边都加装饰。
  • 颜色即信号：青=信息、琥珀=操作/警告、橙=局部强调、绿=成功、红=危险；辉光只做局部反馈。
  • 排版承载结构：中文主命令用粗衬线，正文无衬线，标识符与数值等宽。
  • 靠表面分层，不堆装饰：纸面白与石墨黑对比，不在同一元素上叠边框+渐变+噪点+辉光。
  • 反馈至少改两项：悬停改亮度+位移，按下再叠按压，选中拉起底部信号条。
  • 焦点不被裁切：可点控件的轮廓放在未裁切的外层上。

官方给的失败清单（我第一版几乎全中）：只有黑底 + 青边 + 满屏辉光；每个元素都切角、倾斜、编号；用装饰性数据抢注意力；用"游戏式高密度"为过小控件开脱。
